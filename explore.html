  • 11/22：首屏改为 15 秒静音循环视频，三段依次为 CNC 精加工、满载跌落测试、居家训练，带章节进度与暂停按钮；换重方式更正为“放回底座、单手一推”，Easy 第 3 步、Drop Set 卡与规格抽屉文案已改，不再出现半空卸片或离座换重。
  • 首屏全屏：PC 与 Mobile 首屏都铺满一屏；只保留一个主按钮，取消 Watch the Drop Test 和三支柱胶囊（与下方导航重复）。
  • 支柱导航吸顶：Durable / Accurate / Easy 等锚点在滚动时一直置顶。
  • 高精度：改为大图画廊（一次看一张大图，Mobile 也看得清）加拖拽重量滑块。
  • See the specs：工艺数值展开后讲清“参数是什么、对用户意味着什么”，每屏 5 行。
  • Easy 屏压缩：三张细节图与 Drop Set 卡并为一排，PC 由 1.55 屏压到 1.27 屏。
  • 删除 Your Space 屏；Mobile 与 PC 交互一致（画廊、滑块、步骤、规格、表单均可点击）。
